Cara Pakai — Mudah, Langkah demi Langkah

Panduan ini untuk siapa saja, bahkan yang baru pertama kali. Tidak perlu install apa pun.

? Apa ini?

Ini alat untuk membuat dokumen resmi (Ijazah, SKHU, Nilai Ijazah) secara cepat: Anda cukup memasukkan data santri, lalu aplikasi menata teksnya pada posisi yang benar untuk dicetak di atas blangko asli. Hasilnya bisa langsung dicetak atau diunduh sebagai PDF / Word.

🔒 Semua proses terjadi di HP/komputer Anda. Data tidak dikirim ke server dan tersimpan otomatis di perangkat ini — aman bila tidak sengaja ter-refresh.

⚡ Mulai cepat (3 langkah)

  1. Pilih dokumen di bar atas (mis. Ijazah).
  2. Isi data — lewat ✍️ Input Manual (ketik satu per satu) atau 📥 Upload Excel (banyak data sekaligus).
  3. Cetak dengan 🖨️ Print, atau unduh ⬇️ PDF / ⬇️ Word.

Selesai! Detail tiap langkah ada di bawah.

1 Memilih dokumen

Di bagian 📁 Dokumen (atas), klik salah satu: Ijazah, SKHU, atau Nilai Ijazah.

Setiap dokumen punya datanya sendiri-sendiri. Data di Ijazah tidak tercampur dengan SKHU. Anda bisa bolak-balik tanpa kehilangan data.

Di bawahnya ada papan info: Dokumen aktif, Data siap (jumlah), Ukuran halaman, dan status Tersimpan.

2 Mengisi data

Ada dua cara. Pilih salah satu lewat dua tab: 📥 Upload Excel atau ✍️ Input Manual.

A. Input Manual (ketik langsung)

  1. Klik tab ✍️ Input Manual.
  2. Isi kolom (Nama, Nomor, dll). Pratinjau di kanan otomatis ikut berubah saat Anda mengetik.
  3. Kalau sudah cocok, klik ➕ Tambah ke daftar.
  4. Muncul kotak Beri nama data (otomatis terisi dari Nama, boleh diubah) → klik 💾 Simpan. Data masuk ke Daftar data.
  5. Ulangi untuk santri berikutnya. Form otomatis dikosongkan.
Ketikan yang belum ditambahkan pun ikut tersimpan — kalau ter-refresh, tidak hilang.

B. Upload Excel (banyak data sekaligus)

  1. Klik tab 📥 Upload Excel.
  2. Belum punya file? Unduh contohnya dulu:
    • ⬇️ Format Kosong — hanya judul kolom, siap Anda isi.
    • ⬇️ Contoh Pengisian — sudah berisi 30 baris contoh sebagai panduan.
  3. Isi file Excel itu (jangan ubah nama kolom di baris pertama), simpan.
  4. Klik kotak “Klik untuk pilih file Excel” lalu pilih file .xlsx Anda.
  5. Muncul status hijau “✅ N data terbaca” dan semua data masuk ke daftar.

Mengelola Daftar data

  • Klik salah satu baris untuk melihatnya di pratinjau.
  • Tombol ✕ di tiap baris = hapus satu data itu saja.
  • 🗑️ Kosongkan = hapus semua data di dokumen ini.

3 Pratinjau (panel kanan)

Panel kanan menampilkan persis seperti hasil cetak: teks di atas gambar blangko. Gunakan ◀ dan ▶ untuk berpindah antar data. Angka di tengah (mis. 3 / 30) menunjukkan data ke berapa.

Gambar blangko hanya untuk pratinjau. Saat dicetak/diunduh, file berisi teks saja supaya pas dicetak di atas blangko asli.

4 Mencetak & mengunduh

Di atas pratinjau ada 3 kelompok tombol. Tiap kelompok punya ini (hanya data yang sedang tampil) dan semua (seluruh daftar).

TombolFungsi
🖨️ Print ini / semuaLangsung membuka dialog cetak di browser. Paling praktis untuk mencetak.
⬇️ PDF ini / semuaUnduh file PDF (untuk dicetak nanti atau diarsip).
⬇️ Word ini / semuaUnduh file Word (.docx) bila ingin diedit di Microsoft Word.
Tombol akan nonaktif bila belum ada data. Isi data dulu ya.

5 Mengatur tampilan blangko

Buka ⚙️ Pengaturan lanjutan (di bawah daftar). Di sana:

  • Tampilkan blangko di pratinjau — centang/lepas untuk menampilkan/menyembunyikan gambar blangko.
  • Ganti background blangko — pakai gambar blangko Anda sendiri untuk pratinjau di perangkat ini (memudahkan menyamakan posisi). Ini tidak mengubah milik orang lain.
  • ↩️ Reset background — kembalikan ke blangko bawaan.

6 Mengubah tata letak (opsional)

Kalau posisi teks perlu digeser, klik ✏️ Aktifkan Edit di atas pratinjau. Saat edit aktif, pratinjau menampilkan contoh data terisi supaya mudah menilai posisi & font.

  • Geser teks dengan menyeret, atau pilih lalu pakai tombol panah untuk geser halus.
  • Atur font, ukuran, tebal/miring, rata, warna, dan posisi X/Y pada panel edit.
  • 📐 Ukuran halaman — ganti A4/Letter/F4.
  • 💾 Simpan Default — simpan tata letak di browser ini saja.
  • ↩️ Reset Default — kembalikan ke tata letak bawaan.
Kalau kolom input manual digeser urutannya akan menyesuaikan posisi atas→bawah secara otomatis.

🔑 Untuk pengelola (admin)

Hanya pengelola yang memegang sandi yang bisa mengubah tampilan untuk semua pengunjung.

  1. Klik logo di kiri atas → masukkan sandi. Bila berhasil, logo bercincin hijau.
  2. Masuk ✏️ Aktifkan Edit, atur tata letak / ukuran, lalu klik 🌐 Simpan Global → berlaku untuk semua orang & tersimpan otomatis.
  3. 🖼️ Ganti blangko — unggah gambar blangko baru untuk semua pengunjung.
Bagi pengunjung biasa, tombol ini tidak muncul — jadi template resmi tetap aman.

🛡️ Keamanan & data tersimpan

  • Data tidak dikirim ke server. Semua diproses di perangkat Anda (lihat lencana 🔒 Data lokal — aman).
  • Tersimpan otomatis di browser ini. Refresh atau internet putus tidak menghilangkan data.
  • Data tiap dokumen terpisah dan hanya ada di perangkat Anda.
Catatan: karena tersimpan di browser, data tidak otomatis pindah ke HP/komputer lain. Untuk memindahkan, unduh PDF/Word atau pakai file Excel.

💬 Tanya-jawab singkat

Kenapa hasil cetak hanya teks, tanpa gambar blangko?

Memang sengaja. Dokumen dicetak di atas blangko asli yang sudah ada kop/logonya, jadi file hanya berisi teks agar pas. Gambar di pratinjau cuma alat bantu posisi.

Excel saya tidak terbaca / kolom kurang.

Pastikan nama kolom di baris pertama sama persis dengan contoh. Paling mudah: unduh ⬇️ Format Kosong lalu isi di situ.

Tombol Print/PDF/Word tidak bisa diklik.

Tombol nonaktif bila belum ada data. Tambahkan minimal satu data dulu.

Saya sudah mengetik banyak lalu halaman ke-refresh — hilang?

Tidak. Data & ketikan tersimpan otomatis dan akan kembali saat halaman dibuka lagi di perangkat yang sama.

Perubahan yang saya buat tidak muncul di HP lain.

Penyimpanan bersifat per-perangkat. Untuk berbagi, kirim hasil PDF/Word, atau gunakan akun admin untuk menyimpan tata letak secara global.
